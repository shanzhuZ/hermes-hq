# 04 · 公开资料核查报告（hermes-hq）

**任务**：输入分析分流 →（有社交则）主账号采集 → Maigret → 账号认定 → 公开网页备料 → 已认定账号发文 → 八章成稿。无社交则走人物网页报告（跳过主账号/Maigret/发文）。

## 启动
`skill_view` → **`references/collect-rules.yaml`**（唯一参考）。

## 铁律
- **全程简体中文**；每步以「步骤X：…」呈现；不可跳步
- **步骤0** 必须输出 `[输入分析结论]`，明确 A/B/C
- **步骤2**（A/B）必须用 `mcp_maigret_*`；禁止用 `web_search` 代替跨平台找账号
- **步骤3**（A/B）先采 Maigret 新候选主页佐证，再输出认定结论；禁止重复采种子主页
- **步骤4** 仅 `web_search` / `web_extract` / `browser_*` 为八章备料；A/B **禁止**再搜其它社交账号
- 无可靠公开证据写 **「未核实」**；终稿允许带来源链接
- 终稿必须以文首标题或「一、基本情况」起笔
- **禁止编造**社交账号/handle

## 执行流程（v3.1）

| 步骤 | 节点 | 动作 |
|------|------|------|
| 0 | `step0_intake` | 分析输入；A 有社交 / B 搜到链接回填 / C 确认无社交 |
| 1 | `step1_seed` | 主账号主页（仅 A/B；C 跳过） |
| 2 | `step2_maigret` | Maigret 跨平台（仅 A/B；C 跳过） |
| 3 | `step3_identity` + `step3_profiles` | A/B：先候选主页佐证，再输出 `[账号认定结论]`；C：`[人物锚定结论]` |
| 4 | `step4_osint_web` | 公开信息检索备料（C 加深） |
| 5 | `step5_posts` | 已认定账号发文（C 跳过） |
| 6 | `step7_report` | 八章公开资料核查报告 |

报告首部必须显示姓名。照片两行是可选项：仅在已有可核验的本人头像或公开人物照片 URL
时输出；没有本人图片时，必须同时省略 Markdown 图片与“照片来源”两行，不得输出占位框、
“暂无照片”或无关机构图片。

上述固定章节和二级项均须保留；无可靠公开信息时在对应项写“未核实”或
“未获取可核实信息”，不得删除该项、合并该项或用推测补齐。

## 步骤要点
- **0**：先分流；B 只补主种子链接；C 不要硬跑主页工具。
- **1**：只采主账号，不扩平台。
- **2**：Maigret 出候选清单。
- **3**：A/B 仅采 Maigret 新候选主页后认定归属；C 锚定人物并声明无社交。v3 不做旧版图片核验。
- **4**：按模板章节 `web_search`；C 可多搜。
- **5**：对已认定账号必须实调发文工具。`get_dataset_items` 不要用 `fields` 裁掉作者/id/url。
