二、客家关联度
字段
类型
说明
hakka_level
string
客家关联度，取值1—4：1=客家人；2=可能是客家人或客二代；3=对客家感兴趣的人；4=与客家文化爱好者相关联的人
hakka_reason
string
判定依据。须写明证据类型（籍贯、语言、组织身份、公开活动等）及证据是否闭合；不得仅凭姓氏、居住地推断
三、行业与影响力
字段
类型
说明
industry
string
所属行业或领域，多领域用分号分隔
influence
string
社会/专业影响力评级，建议用“高/中/低”并可在其他字段补充依据
relation_to_china
string
与中国的关联，包括涉华活动、经贸往来、侨团职务、与客属地互动、使领馆/侨务部门公开接触等；须区分事实与推断
attitude_detail
string
公开涉华态度倾向，基于公开言论、活动、立场表述归纳；无记录则写“无法判定”

十一、推荐评估
字段
类型
说明
recommend_level
string
推荐等级，取值“1级”—“5级”；信息严重不足填“无法判定（信息不足）”
recommend_reason
string
定级理由。须对应等级标准中的核心条件编号，列明组织身份、经济价值、政治接触、涉华属性、信息可核验性等支撑，并说明未达更高或为何降级的因素
